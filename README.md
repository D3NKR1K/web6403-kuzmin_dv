# Лабораторная работа №2

## 🌐 Тема проекта

**FloWe Guide** — многостраничный учебный web-сайт-руководство для мобильного приложения FloWe, предназначенного для совместного планирования и хранения общей информации парами.

## 📄 Структура проекта

| Файл                   | Назначение                                                |
| ---------------------- | --------------------------------------------------------- |
| `index.html`           | Главная страница с описанием приложения и его преимуществ |
| `getting-started.html` | Инструкция по началу работы с приложением                 |
| `features.html`        | Страница с таблицей основных возможностей FloWe           |
| `faq.html`             | Страница с часто задаваемыми вопросами                    |
| `style.css`            | Отдельный подключаемый файл каскадных таблиц стилей       |
| `images/`              | Папка с изображениями, используемыми на сайте             |

## 🧩 Реализованные требования

- Разработано **4 HTML-страницы**: главная, «Начало работы», «Возможности» и FAQ
- Использованы **блочные элементы**: `header`, `main`, `section`, `article`, `div`, `table`, `ul`, `ol`, `li`
- Использованы **строчные элементы**: `a`, `span`, `img`
- На сайте есть **внутренние ссылки** между всеми страницами
- На главной странице размещена **картинка**
- На странице «Возможности» добавлена **таблица** с описанием функций приложения
- Стили вынесены в **отдельный файл** `style.css` и подключены на каждой странице
- Использованы разные виды селекторов: селекторы по классу, по тегу, групповые селекторы, псевдоклассы `:hover`, `:first-child`, `:nth-child()` и `:last-child`
- Применены свойства цвета: `color`, `background-color`, `border-color`
- В таблице используются разные виды выравнивания: по левому краю, по центру и по правому краю
- Проект реализован без JavaScript, Bootstrap и других библиотек или фреймворков

## Лабораторная работа № 3

**Цель работы:** изучение основ JavaScript, работа с типами данных, функциями, замыканиями, объектами, массивами, множествами и картами.

**Каркас проекта:** https://github.com/teach-kirshdv/js-tasks

### Задание

Реализовать набор функций на JavaScript в соответствии с заданием лабораторной работы:

- проверка целого числа с использованием побитовых операторов;
- получение массива чётных чисел;
- сумма чисел до заданного значения через цикл и рекурсию;
- факториал числа;
- проверка, является ли число степенью двойки;
- поиск N-го числа Фибоначчи;
- функция создания операции с сохранением состояния;
- генератор арифметической последовательности;
- глубокая проверка равенства объектов.

### Реализованные функции

| Функция                                    | Назначение                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| `isInteger(n)`                             | Проверяет, является ли значение целым числом, используя побитовые операторы   |
| `even()`                                   | Возвращает массив чётных чисел от 2 до 20 включительно                        |
| `sumTo(n)`                                 | Считает сумму чисел от 1 до `n` с помощью цикла                               |
| `recSumTo(n)`                              | Считает сумму чисел от 1 до `n` с помощью рекурсии                            |
| `factorial(n)`                             | Вычисляет факториал числа `n`                                                 |
| `isBinary(n)`                              | Определяет, является ли число степенью двойки                                 |
| `fibonacci(n)`                             | Возвращает N-е число Фибоначчи                                                |
| `getOperationFn(initialValue, operatorFn)` | Создаёт функцию, которая выполняет операцию над сохранённым и новым значением |
| `sequence(start = 0, step = 1)`            | Создаёт независимый генератор арифметической последовательности               |
| `deepEqual(firstObject, secondObject)`     | Рекурсивно сравнивает два значения или объекта по содержимому                 |
